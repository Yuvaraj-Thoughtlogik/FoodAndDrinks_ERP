Order Amount $100.00

Configuration Steps

1

Install the Module

Go to Apps → Search "Stripe Fees" → Install

2

Configure Fees on Stripe Provider

  • Go to Accounting → Configuration → Payment Providers → Stripe
  • Click the "Stripe Fees" tab
  • Enable "Charge Stripe Fees to Customer"
  • Set Domestic Fixed Fee: e.g. 0.30
  • Set Domestic Percentage Fee: e.g. 2.9
  • Optionally set higher rates for International transactions
  • Click Save
3

Fees Apply Automatically

When a customer pays via Stripe — on website checkout or invoice portal — the fee is automatically calculated and added to their payment amount. No extra steps needed.

Stop Absorbing Stripe Fees!

Pass Stripe processing costs to customers — automatically, every time.
