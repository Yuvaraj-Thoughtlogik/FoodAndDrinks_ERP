Overview

Record Quick Preview allows users to open a record form directly in a popup from the list view. This feature improves workflow efficiency by eliminating the need to navigate back and forth between list and form views. Ideal for sales, HR, and inventory teams who frequently review record details.

Features

Eye Icon in List View

Quickly access a form view using an eye icon displayed next to each record.

Popup Form View

Open the form in a smooth, responsive modal popup without reloading the page.

Seamless Integration

Works flawlessly with all Odoo list views for custom and standard models.

User-Friendly Interface

Simple, elegant, and easy-to-use design for faster access to data.
